# AuraGen — Self-Healing Generative UI

**AuraGen** is a Generative AI project that dynamically adapts a user interface based on user interaction and detected cognitive friction.

## 🎯 Objective

Detect when a user is struggling with a complex UI and automatically generate a simpler, conversational interface in real time.

## 🛠️ Tech Stack

* **Frontend:** React, Next.js, Tailwind CSS
* **Backend:** Node.js
* **AI:** LangChain, GPT-4o
* **Real-Time:** WebSockets
* **Code Validation:** Babel AST
* **Animation:** Framer Motion

## 🔄 How It Works

```text
User Interaction
      ↓
Telemetry Tracking
      ↓
Cognitive Load Score
      ↓
LLM detects friction
      ↓
React UI Generation
      ↓
Babel AST Validation
      ↓
Dynamic UI Rendering
```

## 📅 4-Week Plan

**Week 1 — Foundation**

* Build LangChain code-generation pipeline.
* Track mouse movement, hesitation and clicks.
* Stream telemetry using WebSockets.

**Week 2 — Safety & Rendering**

* Validate generated code using Babel AST.
* Build dynamic React component rendering.

**Week 3 — Context & UI Morphing**

* Preserve existing user input and UI state.
* Add smooth UI transitions using Framer Motion.

**Week 4 — Optimization**

* Implement caching and token streaming.
* Reduce redesign latency.
* Add fallback handling for failed generation.

## 🎯 Expected Outcome

A secure, real-time Generative AI system that can detect user difficulty and dynamically transform a complex interface into a simpler, adaptive UI.
